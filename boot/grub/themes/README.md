# GRUB Themes Directory (`boot/grub/themes/`)

This directory houses graphical boot menu themes for GRUB 2.

## Structure
Each theme lives in its own subdirectory containing:
- `theme.txt`: GRUB theme specification defining font properties, colors, box coordinates, and progress bars.
- `background.png` (or `.jpg`): High-resolution background canvas.
- Icons and font files (`.pf2`).

## Default Theme
- `mventx/`: Standard dark minimalist theme matching MVentX brand identity.
